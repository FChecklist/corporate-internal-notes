# Corporate Games: internal release notes (PRIVATE)

For the owner and future maintainers only. Not for any website, not for customers.

- `INTERNAL_NOTES_INDEX.md`: one-page overview of all products and where the details are.
- One folder per product (`tambola`, `bingo`, `tictactoe`, `luckbychance`, `luckydraw`, `snakesladders`, `console`, `home`, `game-core`) with `INTERNAL_RELEASE_NOTES.md`: release number, date and time (IST), commit, Cloudflare deployment id, rollback id, tests, what changed and who decided it, how to roll back, open items.

Rule: when a release goes live, add one row to the product's release table here (and to the handover log).
