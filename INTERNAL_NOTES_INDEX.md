## Family overview

Corporate Games is a family of six online team games for companies, one master console and one public home site, all under corporatetambola.com and all sold only through IT SERVICES BY RAJAT AGARWAL and Razorpay. The six games are Corporate Tambola (housie, housie.corporatetambola.com, the first and most complete game, release 1.9.0), Corporate Bingo (bingo.corporatetambola.com), Corporate Tic Tac Toe (tictactoe.corporatetambola.com), Corporate Snakes and Ladders (snakes.corporatetambola.com), Corporate Luck by Chance (luck.corporatetambola.com, the dice game) and Corporate Lucky Draw (luckydraw.corporatetambola.com, the prize draw for very large crowds). The master console (console.corporatetambola.com) is the one place to sign in and create a game for any of them, with Google sign-in and e-mail code. The home site (home.corporatetambola.com, also reached from corporatetambola.com and www) is the only public site and carries the one legal document at /terms (legal text version 2026-11-01, revision v4). game-core is the shared library of rules, wording, legal text and screens that the games copy in; it is never deployed by itself. The game sites are open by link but hidden from search. ## Things to know

- Eight of the nine GitHub repositories are PUBLIC (only Lucky Draw is private). The notes files therefore sit in public repositories, on a side branch. They contain no passwords, keys or tokens and no customer data, but they do contain deployment ids, project names and internal decisions. The owner may wish to make the repositories private or to keep the notes branch unmerged.
- The notes are written in the repositories' docs folder, which no build ships to a site. Two repositories have tests that read the docs folder (Luck: no internal-note phrases; Snakes and Bingo: no address words); the files were checked against those patterns before they were committed. No test run was made (the laptop has very little free memory).
- The game-core branch `feat/legal-v4-2026-11-02` (444ad31) had not been pushed before; the notes branch carries it to GitHub.
- Times in the notes are the Cloudflare creation times of each deployment (UTC converted to IST), which can differ by a few minutes from the times written in the handover log (for example Tambola 23:04 against 23:08).
- Whoever releases next should append a row to the release table of the affected game's notes and a line to the handover release log.
